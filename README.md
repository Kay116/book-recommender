# 📚 Book Recommender

A Python-based book recommendation program that scrapes book
information from Books to Scrape.

Users can select a category and specify their preferred minimum
rating and maximum price. The program returns the top five
matching books.

## Features

- Choose a book category
- Filter by minimum rating
- Filter by maximum price
- Rank books by rating and price
- Return top 5 recommendations
- Display book descriptions

## Technologies

- Python
- BeautifulSoup
- Requests

## Installation

Install the required packages:

pip install -r requirements.txt

## Run

Run the program:

python src/main.py
